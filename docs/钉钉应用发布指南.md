# 钉钉H5微应用发布流程

## 前提条件
- ✅ Vercel 已部署成功
- 生产地址: `https://dingtalk-workflow-ezk75ewmo-ddtter880s-projects.vercel.app`
- 你必须是钉钉企业的**管理员**或**子管理员**

## 第一步：创建企业内部应用

1. 打开钉钉开发者后台: **https://open-dev.dingtalk.com/**
2. 用管理员钉钉扫码登录
3. 左侧菜单点 **应用开发** → **企业内部开发**
4. 点 **创建应用**
5. 填写：
   - **应用名称**: 工作事项管理系统
   - **应用描述**: 统筹分发审核信息，管理项目进展
   - **应用类型**: H5微应用
   - **开发模式**: 企业自建
6. 点 **确定创建**
7. **立刻记录以下凭证**（非常重要！）：
   - **AppKey** (类似 `dingxxxxxxxxxx`)
   - **AppSecret** (类似 `xxxxxxxxxxxxxxxxxxxxxxxx`)
   - **AgentId** (在应用信息页面)
   - **CorpId** (在组织信息页面)

## 第二步：配置应用

### 2.1 配置安全域名
1. 进入应用 → **开发设置**
2. 找到 **服务器域名** 或 **安全域名**
3. 添加: `dingtalk-workflow-ezk75ewmo-ddtter880s-projects.vercel.app`

### 2.2 配置H5微应用首页
1. 进入应用 → **应用功能** → **网页应用**
2. **应用首页地址**: `https://dingtalk-workflow-ezk75ewmo-ddtter880s-projects.vercel.app`
3. **PC端首页地址**: 同上（或留空）
4. 点 **保存**

### 2.3 申请接口权限
1. 进入应用 → **权限管理**
2. 搜索并申请以下权限：
   - `通讯录用户信息读` (contact:user:readonly)
   - `部门信息读` (contact:department:readonly)
   - `工作通知消息发送` (message:corpconversation:readonly)
   - `待办任务读写` (workrecord:add)
3. 企业内部应用一般**自动审批通过**

## 第三步：配置环境变量

### 3.1 前端变量（Vercel Settings → Environment Variables）
添加以下变量：
```
VITE_DINGTALK_CORP_ID = 你的CorpId
VITE_DINGTALK_AGENT_ID = 你的AgentId
VITE_DINGTALK_APP_KEY = 你的AppKey
VITE_DINGTALK_ROBOT_WEBHOOK = (暂不配)
VITE_DINGTALK_SHEET_ID = (暂不配)
```

### 3.2 后端变量（同一个Vercel Settings页面）
```
DINGTALK_APP_KEY = 你的AppKey
DINGTALK_APP_SECRET = 你的AppSecret
DINGTALK_CORP_ID = 你的CorpId
DINGTALK_AGENT_ID = 你的AgentId
```

### 3.3 重新部署
配完环境变量后，在 Vercel 控制台点 **Redeploy** 触发重新构建

## 第四步：发布应用

1. 回到钉钉开发者后台 → 应用详情页
2. 点 **版本管理与发布**
3. 点 **确认发布**（企业内部应用无需审核）
4. 设置 **可见范围**（选择哪些部门/人员可以使用）

## 第五步：验证

1. 在钉钉手机端或PC端，打开 **工作台**
2. 找到 **工作事项管理系统** 应用
3. 点开，确认能正常加载
4. 测试创建项目、审批等流程
