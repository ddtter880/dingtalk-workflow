# 钉钉宜搭搭建操作手册 - 工作事项管理系统

## 一、创建宜搭应用

### 1.1 进入宜搭平台

1. 打开钉钉客户端，点击底部 **工作台**
2. 搜索 **宜搭**，点击进入
3. 或直接访问 https://www.aliwork.com

### 1.2 创建新应用

1. 点击 **创建应用**
2. 选择 **从空白创建**
3. 填写应用信息：
   - **应用名称**：工作事项管理系统
   - **应用图标**：选择一个合适的图标
   - **应用描述**：统筹分发审核信息，管理项目进展
4. 点击 **确定**

---

## 二、创建流程表单 - 工作事项申报

### 2.1 新建流程表单

1. 在应用中点击 **新建页面**
2. 选择 **流程表单**
3. 命名为 **工作事项申报**

### 2.2 表单字段设计

从左侧组件面板拖入以下字段：

| 序号 | 字段名称 | 组件类型 | 必填 | 说明 |
|------|----------|----------|------|------|
| 1 | 工作事项 | 单行文本 | 是 | 工作事项名称 |
| 2 | 工作要求 | 多行文本 | 否 | 项目负责人明确的工作要求 |
| 3 | 责任部门 | 部门选择 | 否 | 主办部门 |
| 4 | 责任人 | 成员选择 | 否 | 具体负责人（★为牵头人） |
| 5 | 责任领导 | 成员选择 | 否 | 分管领导 |
| 6 | 计划完成时间 | 日期 | 否 | 预计完成日期 |
| 7 | 实际完成时间 | 日期 | 否 | 实际完成日期 |
| 8 | 风险影响 | 多行文本 | 否 | 风险或影响说明 |
| 9 | 进展情况 | 多行文本 | 否 | 当前进展描述 |
| 10 | 需协调事项 | 多行文本 | 否 | 需要议事协调支持的事项 |
| 11 | 建议方案 | 多行文本 | 否 | 建议的处理方案 |
| 12 | 会议精神 | 多行文本 | 否 | 会议决策内容 |
| 13 | 紧急重要程度 | 单选 | 否 | 选项：🔴紧急重要、🟠紧急、🔵重要、⚪一般 |
| 14 | 项目状态 | 单选 | 否 | 选项：新增、待处理、待销项、已销项（默认"新增"） |
| 15 | 是否待销项 | 单选 | 否 | 选项：是、否（默认"否"） |
| 16 | 备注 | 多行文本 | 否 | 补充说明 |
| 17 | 创建周次 | 单行文本 | 否 | 系统自动填写（如2026-W17） |

**配置要点**：
- "紧急重要程度"单选组件：选项值分别为 `urgent_important`、`urgent`、`important`、`normal`
- "项目状态"单选组件：选项值分别为 `new`、`processing`、`pending_close`、`closed`，默认值设为 `new`
- "是否待销项"单选组件：选项值为 `yes`、`no`，默认值设为 `no`

## 三、设计审批流程

### 3.1 进入流程设计器

1. 保存表单后，点击顶部 **流程设计** 标签
2. 进入流程设计器画布

### 3.2 审批节点配置

流程结构：

```
发起人（项目负责人）
    │
    ▼
审批节点1：室所主任
    │
    ▼
审批节点2：分管领导
    │
    ▼
审批节点3：质量安全人员
```

#### 节点1：室所主任

1. 点击 **添加审批节点**
2. 节点名称：**室所主任审核**
3. 审批人设置：选择 **指定成员** → 选择对应的室所主任
4. 字段权限设置（点击节点 → 字段权限）：

| 字段 | 权限 |
|------|------|
| 工作事项 | 只读 |
| 工作要求 | 可编辑 |
| 责任部门 | 只读 |
| 责任人 | 只读 |
| 责任领导 | 只读 |
| 计划完成时间 | 只读 |
| 实际完成时间 | 可编辑 |
| 风险影响 | 可编辑 |
| 进展情况 | 可编辑 |
| 需协调事项 | 可编辑 |
| 建议方案 | 可编辑 |
| 会议精神 | 隐藏 |
| 紧急重要程度 | 只读 |
| 项目状态 | 隐藏 |
| 是否待销项 | 隐藏 |
| 备注 | 可编辑 |
| 创建周次 | 隐藏 |

#### 节点2：分管领导

1. 继续添加审批节点
2. 节点名称：**分管领导审核**
3. 审批人设置：选择 **指定成员** → 选择对应的分管领导
4. 字段权限设置：

| 字段 | 权限 |
|------|------|
| 工作事项 | 只读 |
| 工作要求 | 可编辑 |
| 责任部门 | 只读 |
| 责任人 | 只读 |
| 责任领导 | 只读 |
| 计划完成时间 | 可编辑 |
| 实际完成时间 | 可编辑 |
| 风险影响 | 可编辑 |
| 进展情况 | 可编辑 |
| 需协调事项 | 可编辑 |
| 建议方案 | 可编辑 |
| 会议精神 | 可编辑 |
| 紧急重要程度 | 可编辑 |
| 项目状态 | 隐藏 |
| 是否待销项 | 隐藏 |
| 备注 | 可编辑 |
| 创建周次 | 隐藏 |

#### 节点3：质量安全人员

1. 继续添加审批节点
2. 节点名称：**质量安全人员审核**
3. 审批人设置：选择 **指定成员** → 选择对应的质量安全人员
4. 字段权限设置：

| 字段 | 权限 |
|------|------|
| 工作事项 | 只读 |
| 工作要求 | 可编辑 |
| 责任部门 | 只读 |
| 责任人 | 只读 |
| 责任领导 | 只读 |
| 计划完成时间 | 可编辑 |
| 实际完成时间 | 可编辑 |
| 风险影响 | 可编辑 |
| 进展情况 | 可编辑 |
| 需协调事项 | 可编辑 |
| 建议方案 | 可编辑 |
| 会议精神 | 可编辑 |
| 紧急重要程度 | 可编辑 |
| 项目状态 | 可编辑 |
| 是否待销项 | 可编辑 |
| 备注 | 可编辑 |
| 创建周次 | 只读 |

**关键说明**：
- 质量安全人员节点拥有最大权限，可编辑"项目状态"和"是否待销项"字段
- 质安人员确认销项时，将"项目状态"改为"已销项"，"是否待销项"改为"是"
- 后层级可覆盖前层级数据，符合业务规则

### 3.3 审批驳回设置

每个审批节点都配置：
- **同意**：流转到下一节点
- **拒绝**：退回到发起人（项目负责人）修改后重新提交

### 3.4 保存并发布流程

1. 点击右上角 **保存**
2. 点击 **发布** 使流程生效

## 四、配置数据视图

### 4.1 新增数据视图

在"工作事项申报"表单的数据管理中，创建以下视图：

#### 视图1：新增项目

- **筛选条件**：项目状态 = "新增"
- **排序**：按创建时间倒序
- **条件格式**：
  - 紧急重要程度 = "紧急重要" → 行背景色 #FEF2F2（浅红）
  - 紧急重要程度 = "紧急" → 行背景色 #FFF7ED（浅橙）
  - 紧急重要程度 = "重要" → 行背景色 #EFF6FF（浅蓝）

#### 视图2：待处理项目

- **筛选条件**：项目状态 = "待处理"
- **排序**：按紧急重要程度排序（紧急重要 > 紧急 > 重要 > 一般），再按计划完成时间升序
- **条件格式**：同上

#### 视图3：待销项项目

- **筛选条件**：项目状态 = "待销项"
- **排序**：按创建时间倒序
- **条件格式**：行背景色 #FCE7F3（浅粉）

#### 视图4：已销项项目（垃圾箱）

- **筛选条件**：项目状态 = "已销项"
- **排序**：按实际完成时间倒序
- **说明**：此视图仅管理员可见，用于恢复或永久删除

## 五、配置集成&自动化

### 5.1 周周期自动切换

1. 在表单设置中，点击 **集成&自动化**
2. 点击 **新建自动化**
3. 配置如下：

**触发条件**：定时触发
- **执行时间**：每周一 00:00
- **名称**：周周期状态自动切换

**执行动作**：更新数据
- **目标表单**：工作事项申报
- **筛选条件**：项目状态 = "新增"
- **更新字段**：项目状态 → "待处理"

### 5.2 每周填报提醒

1. 新建自动化
2. 配置如下：

**触发条件**：定时触发
- **执行时间**：每周一 09:00
- **名称**：每周填报提醒

**执行动作**：发送钉钉消息
- **消息内容**：
  ```
  🔔 本周工作事项填报提醒
  请各位项目负责人及时填报本周工作进展！
  待处理项目请在本周五前完成填报。
  ```
- **通知对象**：所有项目负责人

### 5.3 二次提醒（周三）

1. 新建自动化
2. 配置如下：

**触发条件**：定时触发
- **执行时间**：每周三 10:00
- **名称**：填报二次提醒

**执行动作**：发送钉钉消息
- **消息内容**：
  ```
  ⚠️ 工作事项填报提醒（第二次）
  您有未填报的工作事项，请在本周五前完成！
  ```
- **通知对象**：未填报的项目负责人

### 5.4 销项确认通知

1. 新建自动化
2. 配置如下：

**触发条件**：数据更新触发
- **触发条件**：项目状态 变更为 "已销项"
- **名称**：销项确认通知

**执行动作**：发送钉钉消息
- **消息内容**：
  ```
  ✅ 项目"{工作事项}"已确认销项
  销项确认人：{当前操作人}
  销项时间：{当前时间}
  ```
- **通知对象**：@所有人

## 六、配置权限规则

### 6.1 提交权限

- **所有成员**可提交工作事项申报表单

### 6.2 数据查看权限

| 角色 | 可见数据范围 | 配置方式 |
|------|-------------|----------|
| 项目负责人 | 仅查看自己提交的数据 | 权限组：等于当前登录人 |
| 室所主任 | 查看本部门数据 | 权限组：包含当前登录人部门 |
| 分管领导 | 查看下级部门数据 | 权限组：包含下级所有部门 |
| 质量安全人员 | 查看全部数据 | 权限组：管理员权限 |
| 管理员 | 查看全部数据+数据管理 | 应用管理员 |

### 6.3 配置步骤

1. 在表单设置中，点击 **权限设置**
2. 新增权限组：
   - **项目负责人**：提交权限 + 仅查看本人数据
   - **室所主任**：提交权限 + 查看本部门数据
   - **分管领导**：提交权限 + 查看下级部门数据
   - **质量安全人员**：提交权限 + 查看全部数据
   - **管理员**：全部权限

## 七、创建人员配置表（普通表单）

### 7.1 新建普通表单

1. 在应用中点击 **新建页面**
2. 选择 **普通表单**
3. 命名为 **人员配置表**

### 7.2 表单字段

| 字段名称 | 组件类型 | 必填 | 说明 |
|----------|----------|------|------|
| 项目名称 | 单行文本 | 是 | 关联的工作事项名称 |
| 项目负责人 | 成员选择 | 是 | 从组织架构选择 |
| 室所主任 | 成员选择 | 是 | 审批节点1人员 |
| 分管领导 | 成员选择 | 是 | 审批节点2人员 |
| 质量安全人员 | 成员选择 | 是 | 审批节点3人员 |

### 7.3 权限设置

- 仅**管理员**可查看和编辑此表单
- 其他人员不可见

## 八、创建数据报表

### 8.1 新建报表页面

1. 在应用中点击 **新建页面**
2. 选择 **数据报表**
3. 命名为 **工作事项汇总看板**

### 8.2 报表组件

1. **统计卡片**：
   - 新增项目数量
   - 待处理项目数量
   - 待销项项目数量
   - 已销项项目数量

2. **柱状图**：
   - 按紧急重要程度统计项目数量
   - X轴：紧急重要程度
   - Y轴：项目数量

3. **数据表格**：
   - 显示所有项目列表
   - 支持按状态筛选
   - 支持按紧急重要程度排序

## 十、上线发布

### 10.1 发布应用

1. 在应用设置中，点击 **发布**
2. 选择发布范围：**全公司**或**指定部门**
3. 点击 **确认发布**

### 10.2 添加到工作台

1. 在钉钉管理后台，进入 **工作台管理**
2. 将"工作事项管理系统"添加到工作台
3. 设置应用可见范围

### 10.3 培训用户

- 项目负责人：如何创建和提交工作事项
- 室所主任/分管领导：如何审批和补充信息
- 质量安全人员：如何确认销项
- 管理员：如何配置人员和恢复项目
