# 钉钉工作事项管理系统 - 完整配置指南

## 一、系统概述

本系统是一个基于钉钉原生能力的工作事项审核信息分发系统，用于统筹管理项目的多层级上报、审批和销项流程。**无需外部服务器**，完全利用钉钉在线资源。

### 核心功能

| 功能 | 说明 |
|------|------|
| 工作事项分类 | 新增项目（当周）→ 待处理项目（次周起）→ 销项项目 |
| 多层级审批 | 项目负责人 → 室所主任 → 分管领导 → 质量安全人员 |
| 数据覆盖机制 | 后层级可覆盖前层级，历史版本默认隐藏可展开 |
| 销项机制 | 仅质量安全人员可确认销项，销项后进入垃圾箱 |
| 周周期推进 | 每周一自动将"新增"转为"待处理"，每周必填 |
| 紧急重要标识 | 🔴紧急重要 🟠紧急 🔵重要 ⚪一般 |
| 消息通知 | 层级间通知 + 销项全员通知 + 周提醒 |

## 二、钉钉开放平台配置

### 步骤1：创建企业内部应用

1. 访问 [钉钉开放平台](https://open.dingtalk.com/) 并用管理员账号扫码登录
2. 点击左侧 **应用开发 > 企业内部开发**
3. 点击 **创建应用**
4. 填写信息：
   - **应用名称**：工作事项管理系统
   - **应用描述**：统筹分发审核信息，管理项目进展
   - **应用类型**：H5微应用
5. 点击 **确定创建**
6. **记录以下凭证**（非常重要！）：
   - AppKey
   - AppSecret
   - AgentId
   - CorpId（企业ID，在组织信息中查看）

### 步骤2：配置应用信息

1. 进入应用详情页，点击 **开发设置**
2. 配置 **首页地址**：
   - 如果使用Vercel部署：`https://你的域名.vercel.app`
   - 如果使用GitHub Pages：`https://你的用户名.github.io/项目名`
3. 配置 **开发服务器域名**：添加你的H5页面域名
4. 配置 **安全域名**：添加 `https://oapi.dingtalk.com`

### 步骤3：申请接口权限

在应用详情页，点击 **权限管理**，添加以下权限：

| 权限 | 权限标识 | 用途 |
|------|----------|------|
| 通讯录用户信息读 | `contact:user:readonly` | 获取用户信息 |
| 部门信息读 | `contact:department:readonly` | 获取部门信息 |
| 工作通知消息发送 | `message:corpconversation:readonly` | 发送企业消息 |
| 待办任务读写 | `workrecord:add` | 创建/完成待办 |
| 审批实例信息 | `process:processinstance:readonly` | 读取审批状态 |

### 步骤4：配置环境变量

将步骤1获取的凭证填入项目根目录的 `.env` 文件：

```
VITE_DINGTALK_CORP_ID=你的企业ID
VITE_DINGTALK_AGENT_ID=你的AgentId
VITE_DINGTALK_APP_KEY=你的AppKey
VITE_DINGTALK_APP_SECRET=你的AppSecret
VITE_DINGTALK_ROBOT_WEBHOOK=你的机器人Webhook地址
VITE_DINGTALK_SHEET_ID=你的在线表格ID
```

## 四、钉钉OA审批配置

### 创建审批模板

1. 打开钉钉客户端，进入 **工作台 > OA审批**
2. 点击底部 **审批管理 > 审批模板**
3. 点击 **新建审批单 > 从空白创建**

### 设计审批表单

添加以下字段：

| 字段名称 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 项目名称 | 单行文本 | 是 | 工作事项名称 |
| 项目负责人 | 成员选择 | 是 | 从组织架构选择 |
| 紧急重要程度 | 单选 | 否 | 紧急重要/紧急/重要/一般 |
| 工作要求 | 多行文本 | 否 | 工作要求 |
| 进展情况 | 多行文本 | 否 | 当前进展 |
| 风险影响 | 多行文本 | 否 | 风险说明 |
| 需协调事项 | 多行文本 | 否 | 需要协调的内容 |
| 建议方案 | 多行文本 | 否 | 建议处理方案 |
| 是否待销项 | 单选 | 否 | 是/否 |

### 设计审批流程

```
节点1：室所主任（指定成员）
    ↓
节点2：分管领导（指定成员）
    ↓
节点3：质量安全人员（指定成员，含销项确认权限）
```

**配置审批规则**：
- 每个节点可"通过"或"驳回"
- 驳回后返回提交人修改
- 最后一个节点（质量安全人员）可选择"确认销项"

## 五、钉钉机器人配置

### 创建群机器人

1. 创建或选择一个钉钉群（建议命名为"工作事项通知群"）
2. 点击群右上角 **... > 智能群助手 > 添加机器人**
3. 选择 **自定义机器人**
4. 填写信息：
   - **名称**：工作事项通知机器人
   - **安全设置**：勾选 **自定义关键词**，添加：工作事项、审批、销项
5. 点击 **完成**，复制 **Webhook地址**

### 配置定时提醒

1. 在机器人设置页，点击 **定时任务**
2. 添加定时任务：
   - **任务名称**：每周工作提醒
   - **触发时间**：每周一 09:00
   - **消息内容**：
   ```
   @所有人 
   🔔 本周工作事项填报提醒
   请各位项目负责人及时填报本周工作进展！
   ```

## 六、部署到Vercel（推荐）

### 前提条件
- 注册 [Vercel](https://vercel.com/) 账号
- 项目代码推送到 GitHub

### 部署步骤

1. 将项目推送到GitHub仓库
2. 登录Vercel，点击 **Import Project**
3. 选择GitHub仓库，点击Import
4. 配置环境变量（Settings > Environment Variables）：
   - 添加 `.env` 中的所有变量
5. 点击 **Deploy**
6. 部署完成后，获取访问URL（如 `https://your-app.vercel.app`）

### 更新钉钉应用配置

1. 回到钉钉开放平台，更新应用的 **首页地址** 为Vercel提供的URL
2. 更新 **开发服务器域名** 为Vercel域名

## 八、常见问题

### Q1：非钉钉环境能否使用？
A：可以。系统会自动检测运行环境，非钉钉环境下使用localStorage模拟数据存储。

### Q2：如何切换用户角色？
A：在配置页面可以切换模拟角色（开发模式），生产环境通过钉钉OAuth自动获取。

### Q3：数据如何备份？
A：定期在钉钉在线表格中导出数据为Excel文件进行备份。

### Q4：如何修改自动删除周期？
A：管理员在"系统配置"页面可设置垃圾箱自动删除周期（7/15/30/60天）。

### Q5：如何添加新的审批人？
A：管理员在"系统配置"页面的"项目人员配置"中为每个项目分配各层级审批人员。
